# Hermes Desktop Offline (Русский)

**Полноценный ИИ-агент на вашем Windows-ПК — без интернета.**

Другие языки: [English](README.md) · [简体中文](README.zh-CN.md) · [Tiếng Việt](README.vi.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [日本語](README.ja.md)

> **Hermes Desktop Offline** упаковывает десктоп-приложение [Hermes Agent](https://github.com/NousResearch/hermes-agent) в самодостаточный Windows-бандл для работы в air-gap среде: Electron-приложение, runtime Python 3.14, payload агента и 230 навыков — всё проверено SHA-256 и работает с **локальной моделью** (Ollama, LM Studio, vLLM в LAN). Без облачного аккаунта, API-ключей и сети после установки.

## Отличия от онлайн-версии

| Онлайн | **Offline** |
|---|---|
| Интернет нужен для API, обновлений, навыков | **Нулевая зависимость** после установки — работает в air-gap |
| Облачные модели с API-ключом (стоимость, приватность) | Локальные LLM: Ollama / LM Studio / vLLM в LAN |
| Данные на серверах вендора | Всё остаётся в папке установки (`data/`, `work/`, `cache/`) |
| Загрузки при установке | SHA-256 манифест: каждый файл проверяется перед первым запуском |
| Автообновления через интернет | Офлайн ZIP обновления через USB/LAN, проверка целостности, запрет даунгрейда, авто-бэкап |
| Навыки скачиваются по требованию | 230 навыков включены; 31 полностью офлайн, 180 сетевых автоматически отключены |
| Привязка к `%USERPROFILE%` | Портативность: свои пути, запуск с USB-флешки |

**Сценарии применения:** заводы и лаборатории без интернета, государственные air-gap ПК, чувствительные отрасли (медицина, право, финансы), регионы с нестабильной связью.

## Особенности

- 📦 **Один ZIP со всем необходимым** (~1,82 GiB, 58 166 файлов)
- 🔐 **Целостность прежде всего**: `checksums.sha256` (58 165 записей) проверяется при установке
- 🧩 **Безопасные офлайн-навыки**: сетевые навыки автоматически отключаются с указанием причины
- 🔄 **Безопасные офлайн-обновления**: проверка манифеста и checksum, бэкап, обновление по компонентам, запрет даунгрейда
- ⚙️ **Настраиваемые пути**: roots data/work/cache, порт gateway (по умолчанию **8942**), URL локальной модели
- ✅ **Протестировано end-to-end** на Windows 11: распаковка → установка → проверка → запуск; 4 тестовые suites зелёные

## Требования

- Windows 10/11 64-бит (PowerShell 5.1+)
- ~6 ГБ свободного места
- Рекомендуемая локальная модель: Ollama (`http://127.0.0.1:11434/v1`), LM Studio (`http://127.0.0.1:1234/v1`), vLLM в LAN

## Установка (офлайн-машина)

1. Скачайте ZIP из [Releases](https://github.com/tungleqb/hermes-desktop-offline/releases) и скопируйте на целевой ПК (USB подходит).
2. Распакуйте в **короткий путь** (например `D:\hermes`) — MAX_PATH Windows ограничивает глубокие пути.
3. Запустите мастер установки:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File launcher\setup.ps1
   ```
   Неинтерактивно:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File launcher\setup.ps1 `
     -NonInteractive -GatewayPort 8942 -DataRoot E:\hermes-data -LocalBaseUrl http://127.0.0.1:11434/v1 -LocalModel llama3
   ```
4. Проверка: `launcher\verify-offline.ps1`
5. Запуск: двойной клик по `launcher\HermesPortable.exe`

## Обновление без интернета

1. На машине с интернетом: `scripts\build-offline.ps1` создаёт ZIP.
2. Перенесите ZIP на офлайн-машину.
3. `launcher\update-offline.ps1 -Zip D:\transfer\Hermes-Offline-<version>.zip` — проверяет, делает бэкап, обновляет по компонентам, запрещает даунгрейд.

## FAQ

**Нужен ли интернет?** Только чтобы скачать бандл один раз. Установка, проверка, запуск и обновления работают офлайн.
**Какие навыки работают офлайн?** 31 из 230 полностью офлайн; 180 сетевых автоматически отключены.
**Своя модель?** Да — любой OpenAI-совместимый endpoint через `-LocalBaseUrl`/`-LocalModel` или `data\config.yaml`.
